## 致谢说明 | Acknowledgment Policy

我们以多种方式感谢贡献者的工作：

1. **本名单** — 永久记录在此，按首次贡献时间排列
2. **module.json 署名** — 在模块的 `metadata.authors` 中署名
3. **Git 历史** — PR 和 commit 历史永久保留在 GitHub 上
4. **内容目录** — 模块卡片上展示作者信息（计划中）
5. **学术引用** — 作为 LANG 2077 课程的 Case Study，贡献可用于学术作品集

## 如何被添加到名单 | How to Get Added

当你的 Pull Request 被合并后，维护者会自动将你添加到这个名单。你不需要自己修改这个文件。

When your Pull Request is merged, maintainers will automatically add you to this list. You do not need to edit this file yourself.

如果你的信息有误或想要修改显示名称，请提交一个 Issue 或直接联系维护者。

If your information is incorrect or you want to change your display name, please submit an Issue or contact maintainers directly.
