# PhET 模拟与中国小学课程大纲对照分析

> 基于《义务教育数学课程标准（2022年版）》和《义务教育科学课程标准（2022年版）》

---

## 一、课程大纲概览

### 数学 — 四大领域
1. 数与运算 / 数量关系
2. 图形与几何
3. 统计与概率
4. 综合与实践

### 科学 — 四大领域
1. 物质科学（力、能量、物质状态）
2. 生命科学（动植物、人体）
3. 地球与宇宙科学
4. 技术与工程

## 五、按学科分类汇总

### 数学类模拟（新增建议）

```
低年级数学 (1-2年级):
  Counting → 数数/数的认识
  Make a Ten → 凑十法/20以内加减法

中年级数学 (3-4年级):
  Fractions: Intro → 分数的初步认识
  Fraction Matcher → 等价分数/分数比较
  Area Builder → 面积概念
  Area Model Multiplication → 乘法与面积
  Arithmetic → 乘法口诀练习

高年级数学 (5-6年级):
  Fractions: Equality → 通分/异分母分数
  Fractions: Mixed Numbers → 带分数/分数乘除
  Ratio and Proportion → 比和比例
  Number Line: Integers → 数轴/负数
  Equality Explorer → 简易方程 (已有)
```

### 科学类模拟（已有 + 建议新增）

```
低年级科学 (1-2年级):
  Color Vision → 光的初步认识 (已有)
  States of Matter: Basics → 固体液体气体 (建议新增基础版)

中年级科学 (3-4年级):
  Forces and Motion: Basics → 推力拉力 (建议新增)
  Friction → 摩擦力/热传递 (已有)
  Balancing Act → 平衡 (已有)

高年级科学 (5-6年级):
  Gravity Force Lab: Basics → 重力 (建议新增)
  Circuit Construction Kit → 电路 (已有，建议降为小学)
  Energy Skate Park → 能量转化 (已有)
  States of Matter → 相变/物质变化 (已有)
```

## 六、实际教材举例

### 数学真实题目示例

**一年级：** "小明有8颗糖，妈妈又给了他5颗，小明现在有多少颗糖？" → 对应 Make a Ten (凑十法)

**三年级：** "把一个蛋糕平均分成4份，取其中的3份，用分数表示为___" → 对应 Fractions: Intro

**四年级：** "一个长方形，长6厘米，宽4厘米，它的面积是___平方厘米" → 对应 Area Builder / Area Model

**五年级：** "解方程：3x + 5 = 20" → 对应 Equality Explorer (已有)

**六年级：** "学校图书馆有科技书和故事书共1200本，科技书与故事书的比是2:3，各有多少本？" → 对应 Ratio and Proportion

### 科学真实题目示例

**三年级：** "两个小朋友玩拔河比赛，谁用的力大谁就赢。这说明力可以改变物体的___" → 对应 Forces and Motion: Basics

**四年级：** "把冰块放在阳光下，冰会变成___，继续加热会变成___" → 对应 States of Matter

**五年级：** "用电池、导线和小灯泡组装一个简单电路，画出电路图" → 对应 Circuit Construction Kit

**六年级：** "用弹簧测力计测量一个物体的重力，读数为2.5N" → 对应 Gravity Force Lab: Basics
