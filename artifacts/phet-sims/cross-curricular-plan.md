# 跨学科融合方案：科学模拟 × 语文 × 英语
# Cross-Curricular Integration: Science Simulations × Chinese × English

---

## 核心思路

将科学模拟平台从"纯科学工具"升级为**跨学科学习平台**：

```
         ┌──────────────┐
         │   科学模拟    │  ← 核心体验（物理/化学/数学）
         │  (交互探索)   │
         └──────┬───────┘
                │
    ┌───────────┼───────────┐
    ↓           ↓           ↓
┌──────┐   ┌──────┐   ┌──────┐
│ 语文  │   │ 英语 │   │ 数学 │
│ 读写  │   │ 词汇 │   │ 应用 │
└──────┘   └──────┘   └──────┘
```

学生在同一个学习场景中：
1. **做科学探究**（操作模拟）
2. **学科学词汇**（中英文双语）
3. **写观察记录**（语文说明文/科学日志）
4. **练英语表达**（简单句子描述发现）

## 一、语文课标的结合点

### 1.1 2022版语文课标的关键对接

课标中直接支持我们做法的三个要点：

| 课标要求 | 我们的对接方式 |
|---------|-------------|
| **跨学科学习占总课时不少于10%** | 科学模拟本身就是跨学科学习的理想载体 |
| **3-4年级：阅读说明文，了解说明方法** | 模拟配套的学习指南就是"说明文"范本 |
| **5-6年级：写简单说明文，做到"明白清楚"** | 学生用模拟做完实验后写"科学发现报告" |
| **用表格、图像等多种媒介呈现探究所得** | 模拟中的数据图表直接可用 |
| **写简单研究报告（5-6年级）** | 模拟探究 → 记录 → 写报告的完整流程 |

### 1.2 语文融合的具体设计

#### 说明文阅读（3-4年级）

模拟中的"学习指南"本身就是一篇简短的科学说明文。我们可以：
- 在指南中标注说明方法（列数字、打比方、举例子）
- 提问："这段话用了什么说明方法？"

**举例 — 摩擦力模拟的学习指南：**
> 摩擦力就是两个东西互相摩擦时产生的力。**试着快速搓搓你的双手**（举例子）——感觉到变暖了吗？那个热量就是摩擦产生的！我们周围的一切都是由叫做"原子"的**超小粒子**（打比方：比蚂蚁还小几百万倍）组成的。

语文视角的提问：
- "这段话用了哪种说明方法来帮助你理解'原子'？"（打比方）
- "作者为什么让你先搓手再解释原理？"（联系生活经验）

#### 科学日志写作（3-6年级）

每个模拟结束后，引导学生写一段"科学日志"：

**3-4年级模板（简单版）：**
```
我的科学日志
日期：________

今天我探索了：____________（模拟名称）

我发现了：
________________________________
________________________________

让我最惊讶的是：
________________________________

我还想知道：
________________________________
```

**5-6年级模板（说明文版）：**
```
科学探究报告
日期：________  探究主题：____________

一、问题（我想知道什么？）
________________________________

二、预测（我觉得会怎样？为什么？）
________________________________

三、过程（我做了什么？观察到什么？）
________________________________
________________________________

四、发现（结果是什么？和我的预测一样吗？）
________________________________

五、联系（这个发现在生活中哪里能看到？）
________________________________
```

#### 口语表达

- 模拟后"小小科学家发布会"：学生用2-3句话向全班介绍自己的发现
- AI角色可以先示范一段说明文风格的口头讲解，学生模仿

## 二、英语课标的结合点

### 2.1 2022版英语课标的关键对接

| 课标要求 | 我们的对接方式 |
|---------|-------------|
| **核心词汇505个 + 各地扩展100-300个** | 科学词汇可作为扩展词汇 |
| **主题范畴：人与自然** | 物理/化学/生物模拟天然属于此范畴 |
| **反映科技新成果** | 交互式科学模拟本身就是科技手段 |
| **3-4年级课外阅读1500-2000词** | 英文学习指南贡献阅读量 |
| **5-6年级课外阅读4000-5000词** | 英文科学日志 + 指南贡献阅读量 |
| **每周课外视听不少于30分钟** | 英文语音讲解模式 |

### 2.2 科学英语词汇分级表

**核心原则：** 内地小学英语水平较浅（505词基础），所以我们只引入最基础的科学词汇，用"认识"而非"掌握"的标准。

#### 第一级：3-4年级科学英语（最简单的词）

| 模拟 | 中文 | 英文词汇 | 简单句型 |
|------|------|---------|---------|
| 彩色视觉 | 红/绿/蓝/白 | red, green, blue, white, light, color, mix | "Red and blue make purple." |
| 摩擦力 | 热/冷/快/慢 | hot, cold, fast, slow, rub, warm | "Rub your hands. They get warm!" |
| 物质状态 | 冰/水/蒸气 | ice, water, steam, hot, cold, solid, liquid, gas | "Ice is solid. Water is liquid." |
| 平衡探秘 | 重/轻/左/右 | heavy, light, left, right, balance | "The heavy one goes down." |
| 凑十法 | 数字1-20 | one~twenty, add, plus, make, ten | "Seven plus three makes ten." |
| 分数入门 | 一半/部分/整个 | half, part, whole, piece, share, equal | "Cut it in half. Two equal parts." |
| 面积构建 | 大/小/长/宽 | big, small, long, wide, area, square | "This is a big square." |

#### 第二级：5-6年级科学英语（稍有难度）

| 模拟 | 中文 | 英文词汇 | 简单句型 |
|------|------|---------|---------|
| 力与运动 | 推/拉/力 | push, pull, force, move, stop, speed | "Push harder. It moves faster." |
| 能量 | 能量/高度/速度 | energy, height, speed, change, store | "Energy changes from height to speed." |
| 静电 | 电/正/负/吸引 | electricity, charge, attract, spark | "The balloon attracts the paper." |
| 重力 | 重力/地球/月球 | gravity, earth, moon, weight, fall | "Things fall because of gravity." |
| 比和比例 | 比/比例/相等 | ratio, equal, same, compare, proportion | "The ratio is two to three." |
| 数轴 | 正/负/零/数轴 | positive, negative, zero, number line | "Negative two is left of zero." |

### 2.3 英语融合的具体设计

#### 双语标签模式（最轻量）

在模拟界面中，关键元素同时显示中英文：

```
┌─────────────────────────────────────┐
│  温度 Temperature: 100°C            │
│  状态 State: 气体 Gas               │
│  分子速度 Molecule Speed: 快 Fast    │
└─────────────────────────────────────┘
```

#### 科学英语小卡片

每个模拟配3-5张"科学英语卡片"，学生可以在探索时查看：

```
┌─────────────────────────────┐
│  🔬 Science Word            │
│                             │
│  摩擦力 = Friction          │
│  [frik-shun]               │
│                             │
│  "Friction makes things     │
│   warm when they rub."      │
│                             │
│  摩擦让东西在摩擦时变暖。     │
│                             │
│  🔊 (点击听发音)             │
└─────────────────────────────┘
```

#### 英语表达练习（可选模块）

在反思环节后加一个可选的"用英语说一说"：

**3-4年级（选词填空）：**
```
Fill in the blanks:
When I _____ (rub/push) my hands together,
they get _____ (cold/warm).
This is called _____ (friction/gravity).
```

**5-6年级（看图说话）：**
```
Look at what happened in the simulation.
Can you describe it in English?

Example: "I added heat to the ice.
The molecules moved faster.
The ice changed to water.
This is called melting."

Now you try:
I ________________________________________
The ______________________________________
This is called ____________________________
```

## 三、数学语境下的语文英语融合

数学类模拟天然适合融合语言教学，因为数学概念需要精确的语言表达。

| 数学模拟 | 语文练习 | 英语练习 |
|---------|---------|---------|
| **凑十法** | 写一写：用"因为...所以..."解释凑十的方法 | "Seven plus three equals ten." |
| **分数入门** | 说一说：生活中哪里用到了分数？（说明文风格） | "One half is the same as two quarters." |
| **面积构建** | 画一画，写一写：描述你设计的图形的面积 | "The area of my rectangle is twelve squares." |
| **比和比例** | 小调查报告：班里同学喜欢的水果比例 | "The ratio of apples to oranges is three to two." |
| **平均数** | 用数据写一段分析文字 | "The average height is one hundred and thirty centimeters." |

## 四、产品设计方案

### 4.1 在每个模拟中增加"语言角"

```
模拟界面布局：

┌──────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────┐ │
│  │                                          │ │
│  │          科学模拟（交互区）               │ │
│  │                                          │ │
│  └──────────────────────────────────────────┘ │
│                                               │
│  ┌────────┐  ┌────────┐  ┌────────┐          │
│  │学习指南│  │科学词汇│  │我的发现│          │
│  │(中文)  │  │(中英文)│  │(写作区)│          │
│  └────────┘  └────────┘  └────────┘          │
└──────────────────────────────────────────────┘
```

### 4.2 三个可切换的标签页

| 标签 | 内容 | 对应学科 |
|------|------|---------|
| **学习指南** | 科学概念说明文 + 操作引导 | 科学 + 语文(阅读) |
| **科学词汇** | 中英文对照词汇卡 + 发音 | 英语 |
| **我的发现** | 写作模板(科学日志/报告) | 语文(写作) + 英语(可选) |

### 4.3 功能层次

| 层次 | 功能 | 优先级 |
|------|------|--------|
| **基础层** | 双语标签（界面中英文对照） | 已有基础 |
| **词汇层** | 科学英语词汇卡 + 发音 | 新增 |
| **阅读层** | 学习指南作为说明文范本 | 已有基础，可强化 |
| **写作层** | 科学日志/探究报告模板 | 新增 |
| **口语层** | "用英语说一说"练习 | 新增 |
| **AI层** | AI批改写作，给出反馈 | 未来 |

## 五、教学理念的对齐

### 5.1 三科课标的共通点

| 共通理念 | 语文课标 | 英语课标 | 科学课标 |
|---------|---------|---------|---------|
| **核心素养导向** | 文化自信+语言运用+思维+审美 | 语言能力+文化意识+思维品质+学习能力 | 科学观念+科学思维+探究实践+态度责任 |
| **跨学科整合** | 跨学科任务群(占10%+) | 主题引领，人与自然 | 综合实践 |
| **真实情境** | 在真实语言运用情境中表现 | 紧密联系现实生活 | 联系生活实际 |
| **自主探究** | 梳理与探究 | 学思结合，用创为本 | 探究式学习 |
| **多模态呈现** | 表格、图像、音频等多种媒介 | 视听结合 | 实验记录、数据图表 |

**核心发现：三科课标都强调"在真实情境中跨学科整合"，我们的科学模拟平台天然就是这个"真实情境"。**

### 5.2 CLIL方法论的应用

CLIL(内容与语言整合学习)的4C框架完美适配我们的平台：

| 4C要素 | 在我们平台的体现 |
|--------|----------------|
| **Content（内容）** | 科学/数学模拟的学科知识 |
| **Communication（交流）** | 中英文科学词汇、写科学日志、口头描述发现 |
| **Cognition（认知）** | 预测→验证→分析→反思的探究思维 |
| **Culture（文化）** | 科学精神、国际科学术语、跨文化科学素养 |

### 5.3 关键注意事项

- **英语不加负担：** 英语词汇是"接触性学习"，不考试、不强制，鼓励但不要求
- **语文自然融入：** 写科学日志本身就是语文写作练习，不额外增加任务
- **科学为主体：** 科学探究是核心，语文英语是增值，不能喧宾夺主
- **分层可选：** 语言练习作为可选模块，不影响科学学习的完整性

## 六、实施路线

### 第一步（近期）
- 在现有学习指南中增加"说明方法"标注
- 为每个模拟添加5-8个科学英语词汇卡（中英对照 + 发音）
- 添加简单的"我的发现"写作模板

### 第二步（中期）
- 完善科学日志/探究报告模板，分3-4年级版和5-6年级版
- 添加"用英语说一说"选词填空练习
- AI语音朗读英文词汇和例句

### 第三步（长期）
- AI辅助批改科学日志
- 生成个性化英语词汇学习路径
- 教师端查看学生的写作记录和词汇学习进度
