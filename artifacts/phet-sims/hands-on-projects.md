# 从屏幕到现实：每个模拟配套的动手实践项目
# Screen to Reality: Hands-On Projects Paired with Every Simulation

---

## 核心理念

```
模拟不是终点，而是起点。

    屏幕上探索          现实中动手          回到屏幕验证
  ┌──────────┐      ┌──────────┐      ┌──────────┐
  │ 先在模拟中 │  →   │ 用真实材料 │  →   │ 再回模拟中 │
  │ 观察规律   │      │ 动手制作   │      │ 对比验证   │
  └──────────┘      └──────────┘      └──────────┘
   "我发现加热          "我真的用           "模拟里的分子
    分子会动得快"        冰做了实验！"        和我看到的一样！"
```

**三阶段循环：模拟探索 → 动手实践 → 回屏验证**

这不是"模拟 OR 实验"的选择题，而是"模拟 AND 实验"的闭环。模拟让孩子先建立直觉，动手让孩子亲身验证，再回到模拟对比深化理解。

---

## 设计原则

| 原则 | 说明 |
|------|------|
| **低成本** | 每个项目人均成本控制在5元以内，大部分1元以内 |
| **家校通用** | 可在教室做，也可以布置为家庭作业 |
| **安全第一** | 不用火、不用强化学品，小学生可独立完成 |
| **看得见成果** | 每个项目都有一个可以展示的实物作品 |
| **与模拟直接对应** | 动手项目验证的就是模拟中探索的同一个概念 |

## 一、小学物理类

### 1. 摩擦力 → 摩擦力大比拼

**模拟中学到的：** 摩擦产生热量，原子运动越快温度越高

**动手项目：摩擦力大比拼**

| 项目 | 详情 |
|------|------|
| 材料 | 小木块1个、橡皮筋1根、不同表面（桌面、砂纸、毛巾、玻璃板） |
| 成本 | 约1元 |
| 时间 | 20分钟 |

**做法：**
1. 用橡皮筋拉着小木块在不同表面上滑动
2. 观察橡皮筋拉长多少——拉得越长说明摩擦力越大
3. 用手摸摸滑动后的表面——感受温度变化
4. 记录结果表格：

```
表面        橡皮筋拉长(厘米)    摸起来(冷/温/热)
─────────  ───────────────    ─────────────
光滑桌面     ___               ___
砂纸         ___               ___
毛巾         ___               ___
```

5. **回屏验证：** 在模拟中，摩擦快的时候原子抖动更剧烈——和你摸到的"变热"是同一件事！

**可展示成果：** 一张"摩擦力大小排行榜"海报

### 2. 彩色视觉 → 三原色混色盘

**模拟中学到的：** 红+绿=黄，红+蓝=品红，绿+蓝=青，三色=白

**动手项目：三原色旋转混色盘**

| 项目 | 详情 |
|------|------|
| 材料 | 白色圆卡纸、红绿蓝彩色笔、牙签或铅笔、胶水 |
| 成本 | 约0.5元 |
| 时间 | 15分钟 |

**做法：**
1. 在圆卡纸上画三等分扇形，分别涂红、绿、蓝
2. 中心穿一根牙签做成陀螺
3. 快速旋转——观察颜色变成了什么？
4. 试试只涂两种颜色的组合，旋转看效果
5. **回屏验证：** 在模拟中把三色滑块都拉到最大——是不是和你的陀螺旋转效果一样？

**可展示成果：** 自己做的彩色陀螺 + "颜色混合发现表"

### 3. 平衡探秘 → 硬币跷跷板

**模拟中学到的：** 重的物体靠近中心，轻的物体远离中心，就能平衡

**动手项目：尺子跷跷板实验**

| 项目 | 详情 |
|------|------|
| 材料 | 30cm直尺1把、铅笔1支（做支点）、硬币若干（1角和1元） |
| 成本 | 约0元（教室里就有） |
| 时间 | 15分钟 |

**做法：**
1. 把尺子架在铅笔上，找到平衡点
2. 一边放1枚1元硬币，另一边放几枚1角硬币使其平衡
3. 移动硬币的位置，发现：离中心越远，"力量"越大！
4. 记录：1元硬币在刻度X时，需要把1角硬币放在刻度Y才能平衡
5. **回屏验证：** 在模拟中放同样比例的重物，验证距离和重量的关系

**可展示成果：** "平衡密码"记录卡——标注每种组合的平衡位置

### 4. 物质状态 → 冰的三态观察站

**模拟中学到的：** 加热让分子运动加快，固态→液态→气态

**动手项目：冰块融化观察站**

| 项目 | 详情 |
|------|------|
| 材料 | 冰块3块、透明杯3个、盐/糖/什么都不加、温度计（可选） |
| 成本 | 约0.5元 |
| 时间 | 30分钟（含等待观察） |

**做法：**
1. 三个杯子各放一块冰：第一杯加盐，第二杯加糖，第三杯什么都不加
2. 每5分钟记录一次：哪个杯子的冰融化最多？
3. 画"分子运动图"：固态=排列整齐，液态=缓慢移动，气态=到处飞
4. 延伸：对着冷镜子哈气——水蒸气在哪里变成了小水滴？
5. **回屏验证：** 在模拟中调温度，看分子运动是不是和你画的一样

**可展示成果：** 三态变化折页小书（画+文字）

### 5. 能量滑板公园 → 弹珠过山车

**模拟中学到的：** 高处=储存能量，低处=速度能量，能量不会消失

**动手项目：纸筒弹珠过山车**

| 项目 | 详情 |
|------|------|
| 材料 | 卫生纸筒3-4个（剪开做轨道）、胶带、弹珠1颗、纸箱/书本（做高度） |
| 成本 | 约0元（废旧材料） |
| 时间 | 30分钟 |

**做法：**
1. 把纸筒纵向剪开做成半管轨道
2. 用胶带和书本搭建一个起伏的过山车轨道
3. 从不同高度放弹珠，观察它能滚多远
4. 挑战：能不能让弹珠翻过一个环？需要多高的起点？
5. 记录：起点高度 → 弹珠到达的最远距离
6. **回屏验证：** 在模拟中调整滑板选手的起始高度，看速度变化

**可展示成果：** 一座可以展示的纸筒过山车！

### 6. 力与运动(基础) → 拉力小车

**模拟中学到的：** 力越大，物体加速越快；摩擦力会让物体减速

**动手项目：橡皮筋动力小车**

| 项目 | 详情 |
|------|------|
| 材料 | 纸盒1个（如牙膏盒）、瓶盖4个（做轮子）、竹签2根（车轴）、橡皮筋 |
| 成本 | 约1元 |
| 时间 | 30分钟 |

**做法：**
1. 瓶盖中心打孔，穿入竹签做成带轮子的车轴
2. 安装到纸盒底部
3. 用橡皮筋缠绕在后轮轴上——拧紧后松手，小车会跑！
4. 实验：在光滑地面和粗糙地面（铺毛巾）上分别跑——哪个更远？
5. 实验：橡皮筋拧多少圈 vs 小车跑多远？记录数据
6. **回屏验证：** 在模拟中增大力/减小摩擦，看效果是否一致

**可展示成果：** 自己做的橡皮筋动力车 + 距离测试数据表

### 7. 静电 → 静电魔术秀

**模拟中学到的：** 摩擦可以让物体带电，带电物体能吸引轻小物体

**动手项目：气球静电实验**

| 项目 | 详情 |
|------|------|
| 材料 | 气球1个、碎纸屑、毛衣/头发、空易拉罐 |
| 成本 | 约0.3元 |
| 时间 | 15分钟 |

**做法：**
1. 气球在头发或毛衣上快速摩擦
2. 靠近碎纸屑——纸屑会跳起来粘到气球上！
3. 靠近细水流——水流会弯曲！
4. 把气球靠近桌上的空易拉罐——易拉罐会滚向气球！
5. **回屏验证：** 在"气球与静电"模拟中，看电子是怎么转移的

**可展示成果：** "静电魔术"表演视频/照片集

### 8. 摆钟实验室 → 自制摆钟

**模拟中学到的：** 摆的长度决定快慢，重量不影响

**动手项目：绳子摆实验**

| 项目 | 详情 |
|------|------|
| 材料 | 细绳（30cm/50cm/70cm各一段）、橡皮/小石头（重物）、桌子边缘、秒表 |
| 成本 | 约0.5元 |
| 时间 | 20分钟 |

**做法：**
1. 把不同长度的绳子拴上相同重量的橡皮，挂在桌子边缘
2. 拉到同一角度放手，数10秒内摆了几次
3. 换不同重量的重物（大橡皮vs小橡皮），发现：次数没变！
4. 记录：绳长 → 每10秒摆动次数

```
绳长(cm)    重物    10秒摆动次数
─────────  ──────  ───────────
30cm       小橡皮    ___
30cm       大橡皮    ___
50cm       小橡皮    ___
70cm       小橡皮    ___
```

5. **回屏验证：** 在模拟中只改长度不改重量，验证你的发现

**可展示成果：** 数据表格 + "摆的秘密"结论卡

## 二、小学数学类

### 9. 凑十法 → 凑十积木塔

**模拟中学到的：** 两个数凑成10的方法

**动手项目：积木凑十配对**

| 项目 | 详情 |
|------|------|
| 材料 | 10块积木（或10颗棋子/10颗糖果）、数字卡片1-9 |
| 成本 | 约0元 |
| 时间 | 15分钟 |

**做法：**
1. 摆出10块积木排成一排
2. 用手分成两堆：3和7、4和6、5和5……
3. 每分一次就写一张算式卡：3+7=10
4. 找出所有的凑十组合
5. 延伸：用真实水果或糖果来分——更有趣！
6. **回屏验证：** 在模拟中操作凑十，检查是不是都找到了

**可展示成果：** "凑十大全"卡片套装

### 10. 分数入门 → 切披萨学分数

**模拟中学到的：** 分数就是把一个整体分成相等的几份

**动手项目：纸盘披萨分数**

| 项目 | 详情 |
|------|------|
| 材料 | 纸盘3-4个（画成"披萨"）、剪刀、彩色笔 |
| 成本 | 约1元 |
| 时间 | 20分钟 |

**做法：**
1. 把纸盘画成披萨（加上"料"的图案更好玩）
2. 第一个对折剪开——每份是1/2
3. 第二个折两次剪开——每份是1/4
4. 第三个折三次——每份是1/8
5. 拼一拼：2个1/4 = 1个1/2 吗？叠在一起验证！
6. **回屏验证：** 在模拟中操作分数，和你的纸盘对比

**可展示成果：** 一套可以拆分拼合的"分数披萨教具"

### 11. 面积构建 → 方格地图设计师

**模拟中学到的：** 面积 = 数方格，长方形面积 = 长 x 宽

**动手项目：设计我的梦想教室**

| 项目 | 详情 |
|------|------|
| 材料 | 方格纸、彩色笔、直尺 |
| 成本 | 约0.5元 |
| 时间 | 25分钟 |

**做法：**
1. 在方格纸上画出一个"教室"的轮廓
2. 设计放哪些家具：桌子(2x3格)、书柜(1x4格)、讲台(3x2格)……
3. 计算每个家具的面积（数方格或用乘法）
4. 计算教室总面积，减去家具面积 = 可以走动的面积
5. 挑战：能不能重新排列家具让走动空间更大？
6. **回屏验证：** 在面积模拟中用同样的数字构建形状

**可展示成果：** 一张"梦想教室设计图"，标注每个区域面积

### 12. 比和比例 → 果汁调配大师

**模拟中学到的：** 比就是两个量之间的关系

**动手项目：果汁浓度实验**

| 项目 | 详情 |
|------|------|
| 材料 | 果汁浓缩液（或糖浆）、水、量杯3个、汤匙 |
| 成本 | 约2元 |
| 时间 | 15分钟 |

**做法：**
1. 三杯水用不同比例加果汁：1:3、1:5、1:8
2. 品尝：哪杯最甜？哪杯最淡？

4. 挑战：如果要做一大壶（8杯），你最喜欢的比例需要多少果汁和多少水？
5. **回屏验证：** 在模拟中调整比例滑块，理解等比关系

**可展示成果：** "黄金比例果汁配方卡"

## 三、小学化学/生科类

### 13. 物质状态(基础) → 巧克力三态实验

**模拟中学到的：** 加热让固体变液体再变气体

**动手项目：巧克力融化观察**

| 项目 | 详情 |
|------|------|
| 材料 | 巧克力2-3小块、热水（不用火！用保温杯里的热水）、冰箱 |
| 成本 | 约3元 |
| 时间 | 30分钟 |

**做法：**
1. 观察并画出固体巧克力的样子
2. 放在密封袋里，浸入热水——观察慢慢变软变液的过程
3. 拿出来趁软时用手指捏成一个新形状
4. 放进冰箱——又变回固体了！但形状变了！
5. 讨论：巧克力变了形状，但还是巧克力吗？（物理变化vs化学变化）
6. **回屏验证：** 模拟中加热/冷却时分子排列的变化

**可展示成果：** 自己捏的巧克力新形状 + 三态变化记录卡

## 四、综合工程挑战项目

这些是跨多个模拟概念的综合性Maker项目，适合作为单元结束的大项目。

### 14. 纸桥承重挑战（力+平衡+结构）

| 项目 | 详情 |
|------|------|
| 材料 | A4纸5张、胶带30cm、两本相同厚度的书（做桥墩） |
| 成本 | 约0.5元 |
| 时间 | 40分钟 |

**做法：**
1. 两本书相隔20cm做桥墩
2. 只用5张纸和胶带建一座桥
3. 在桥上放硬币测试承重——能放几枚？
4. 折叠方式不同，承重天壤之别！（波纹/管状/三角形结构）
5. 全班比赛：谁的桥承重最多？

**涉及模拟：** 平衡探秘（力和距离）、力与运动（力的分布）

### 15. 简易乐器工坊（声音+振动+数学）

| 项目 | 详情 |
|------|------|
| 材料 | 8个相同玻璃杯、水、金属勺、橡皮筋、纸盒 |
| 成本 | 约3元 |
| 时间 | 30分钟 |

**做法：**
1. 8个杯子装不同高度的水，用勺子敲——做成一组"水杯琴"
2. 水多的音低，水少的音高——为什么？
3. 在纸盒上绑不同粗细的橡皮筋弹奏——做成"橡皮筋吉他"
4. 能不能弹出一首简单的歌？
5. 测量每个杯子的水量，找到音高和水量的数学关系

**涉及模拟：** 声波（频率与音高）、比和比例（水量比例）

### 16. 纸杯电话（声音传播 + 材料科学）

| 项目 | 详情 |
|------|------|
| 材料 | 纸杯2个、棉线3-5米、牙签2根 |
| 成本 | 约0.5元 |
| 时间 | 15分钟 |

**做法：**
1. 杯底穿孔，穿入棉线，用牙签固定
2. 两人各拿一个杯子拉紧线——一人说一人听

4. 换不同材料的线（棉线vs尼龙线vs铁丝）——哪个最清楚？
5. **回屏验证：** 声波模拟中观察振动是如何传播的
