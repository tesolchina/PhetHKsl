# PhET 全部模拟目录 — 小学适用性筛查

筛查范围：PhET GitHub 全部仓库（phetsims org, 208 repos）
筛查目标：识别适合中国小学（1-6年级）的模拟，对应2022版课标

## 筛查标准

| 等级 | 含义 | 标记 |
|------|------|------|
| **A 级** | 直接适用小学，PhET官方标记 elementary | ★★★ |
| **B 级** | 可用于小学高年级(5-6年级)，需简化引导 | ★★ |
| **C 级** | 初中及以上，不适合小学 | ★ |
| **--** | 非模拟仓库（框架/工具库） | -- |
